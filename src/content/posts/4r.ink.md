# 关于 4r.ink

`4r.ink` 是为备案而准备的域名。

## 当前状态

- **用途**：备案预留，暂无直接服务
- **注册商**：Spaceship（60 天锁定期内，约 2026-08-26 起可转注册商）
- **CDN**：阿里云边缘安全加速（ESA）
- **DNS**：aTrustDNS（ESA 自带：`van.ns.atrustdns.com` / `dykh-tau.ns.atrustdns.com`）

## 未来规划

备案落地后接入阿里云国内 CDN，搭建完整链路：

用户 → 4r.ink 国内 CDN → g7.at 境外回源 → 境外存储（B2 / HF / Tigris / E2 / SUFY）

配合 `g7.at` 子域名（B2 / HF / Tigris / E2 / SUFY / i 图床）作为海外回源中转，给国内访问提供加速。

## 进展

| 时间 | 节点 |
|---|---|
| 2026-06-27 | Spaceship 接管（注册日期） |
| 2026-08-26 | 锁定期结束，可转注册商 |
| 2026 Q4（预估） | 备案落地 |

备案前置条件：转入国内注册商 + 有云服务器 + 实名认证。
