## 首页观测

| 指标 | 基线 |
|---|---:|
| DOMContentLoaded | 40.2 ms |
| load | 54.9 ms |
| FCP | 52 ms |
| 用户操作前音频请求 | 1 个 |

| 该请求在本次观测中的持续时间 | 约 15,023 ms |

首页本身很快；最大的确定性浪费是播放器 `preload="metadata"` 在用户未播放时就请求 4.2 MB 音频文件。静态服务器没有提供可靠的压缩传输统计，因此不把本次 `transferSize` 当作有效字节基线。
