# 性能优化报告

## 结论

首页在用户点击播放前不再下载音频数据，消除了一个确定性的非必要媒体请求。基线中该请求对应 4,209,569-byte 文件，并在本地观测中持续约 15 秒。侧栏播放器改为空闲时水合，避免与首页关键加载阶段竞争。

## 前后对比

| 指标 | 优化前 | 优化后 | 变化 |
|---|---:|---:|---:|
| 用户操作前音频请求 | 1 | 0 | -100% |
| 用户操作前可能触发的音频文件体积 | 4,209,569 bytes | 0 bytes | -100% |
| 播放器水合时机 | 页面加载 | 浏览器空闲 | 移出关键加载阶段 |
| 固定背景图片 | 229,486 bytes | 89,932 bytes | -60.8% |
| 首屏头像图片 | 30,624 bytes | 4,680 bytes | -84.7% |
| 首页 CSS | 12 个 / 283,407 bytes | 11 个 / 192,682 bytes | -32.0% bytes |
| 深度优化阶段 `dist` 总大小 | 12,958,030 bytes | 11,076,887 bytes | -14.5% |
| KaTeX 发布字体 | 60 个 / 1,076,572 bytes | 20 个 / 259,792 bytes | -75.9% |
| Roboto 发布字体 | 48 个 / 656,144 bytes | 9 个 / 137,044 bytes | -79.1% |
| 未使用 Pagefind UI | 418,109 bytes | 0 bytes | -100% |

没有把未限速的单次本地耗时包装成 p75。本环境未配置 Fast 4G 冷缓存的成组配对测试，因此本报告只对确定性请求计数和功能回归下结论。

## 护栏结果

- `npm run build`：通过，24 个页面生成成功。
- `npm run perf:check`：通过，首页不存在 eager media preload。
- `agent-browser`：首页有内容、无错误遮罩、主要交互元素可访问。
- 亮色首页三轮优化后的截图均与各自前一版本保持 0% 像素差；暗色文章页渲染正常。
- Pagefind 实际搜索、越南语字体子集、KaTeX WOFF2 加载和 Open Graph 图片元数据均通过浏览器检查。
- 音乐冒烟：点击播放后音频为播放状态，资源地址正确。
- Bilibili 资源的 `referrerpolicy="no-referrer"` 未被修改。

## 上线与回滚

- 本轮未部署；上线仍需用户批准。
- 回滚：恢复两个播放器的 `preload="metadata"`，并把侧栏播放器恢复为 `client:load`。

## 已知事项

- 构建仍有 3 条本轮之前就存在的 CSS HTML 实体转义警告。
- `npm run check` 仍被仓库中 46 个既有类型错误阻塞；本轮修改的三个播放器文件没有出现在诊断中。
- 如需严格的延迟百分比，应在可全请求限速的环境中对基线版本和当前版本按 A/B/A/B 各跑至少 10 次。
